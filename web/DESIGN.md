# 秘域 · Mysterious Realm · 设计契约

## 使命
让中文用户在安静、神秘而可信赖的星幕中完成对话、抽牌与逐牌解读；管理功能藏在独立入口，不干扰占卜体验。

## 设计令牌
- **色彩**：夜色背景 `#0c0914`，层叠表面 `#151020 / #1c1429`；主色星紫 `#a989e8`，强调月金 `#e7c98f`，正文 `#f3edf9`，次文 `#b8acc7`；成功 `#78c7ad`、危险 `#ed8d9e`。颜色同时配合文字或图标表达状态。
- **字体**：系统中文无衬线负责操作与正文，宋体负责标题与牌名；正文 14–16px，标题使用流体式层级。
- **间距**：以 4px / 8px 为节奏，常用 4、8、12、16、24、32px。
- **圆角**：控件 10px、卡片 16px、仪式与浮层 24px；胶囊只用于短状态。
- **动效**：悬停与按压 120–180ms，列表错落入场 360ms；仅动画 transform / opacity / 边框等必要属性。尊重 reduced-motion。

## Do / Don't
- Do：保留宽阔留白、细星轨、半透明紫光与清晰焦点；所有图标按钮提供中文标签或 tooltip。
- Do：长文自然换行，桌面数据用表格、窄屏转为卡片；牌面缺失仍展示可识别的中文牌名。
- Don't：不向用户暴露模型选择、原始 JSON 或技术错误堆栈；不用大面积说明文字代替短 hint。
- Don't：不用动画伪造抽取结果，不让装饰降低输入、阅读和键盘操作可用性。
