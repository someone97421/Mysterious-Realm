# 塔罗牌面素材

本目录提供完整的 78 张 Rider–Waite–Smith 风格牌面，供应用随包分发。图片路径统一为 `/cards/{card_id}.jpg`，具体牌名、牌组、来源页面、原图 SHA-1、许可依据和生成尺寸记录在 [`web/public/cards/manifest.json`](../web/public/cards/manifest.json) 中。

## 来源与许可

- 来源站点：Wikimedia Commons。
- 来源牌组分类：[Rider-Waite-Smith tarot deck (Geldard)](https://commons.wikimedia.org/wiki/Category:Rider-Waite-Smith_tarot_deck_(Geldard))。
- 每张牌都使用 Commons 的单独文件页面；`manifest.json` 的 `source_url` 是该页面，`source_image_url` 是对应原始 PNG，便于逐项复核。
- Commons 页面元数据逐张标记为 `Public domain`，并包含 `CC-PD-Mark` 分类、`PD-old`/作者逝世超过 70 年的公版依据；元数据中的作者为 Pamela Colman Smith，原作日期为 1910。项目按 [Creative Commons Public Domain Mark 1.0](https://creativecommons.org/publicdomain/mark/1.0/) 记录该依据。
- Commons 元数据同时标记 `AttributionRequired: false`。因此应用分发不要求署名；为便于追溯，应用仍保留来源页面、原图 URL 与 SHA-1，不把来源信息从 manifest 中省略。

这些结论对应下载时逐张读取的 Commons 文件元数据，而不是仅由“可下载”推断许可。发布到特定司法辖区前，应以 manifest 中的来源页面和当地公版规则复核。

## 牌面与文件约定

- 大阿卡纳：`major_00` 至 `major_21`。编号遵循塔罗大师定义：`major_08` 为力量，`major_11` 为正义。
- 小阿卡纳：`wands_01` 至 `wands_14`、`cups_01` 至 `cups_14`、`swords_01` 至 `swords_14`、`pentacles_01` 至 `pentacles_14`。
- 小阿卡纳编号为王牌、二至十、侍从、骑士、王后、国王；中文名和英文名以 `manifest.json` 为准。Commons 个别历史文件名把宝剑和星币的王牌写作 “One of …”，manifest 仍按牌面规范记录为 Ace，并保留实际来源 URL。

## 交付核对

- 图片数量：78 张 JPG；大阿卡纳 22 张，权杖、圣杯、宝剑、星币各 14 张。
- 图片尺寸：全部 500×858 px，保留完整牌面细节。
- 图片总大小：13,163,148 bytes（约 12.55 MiB）。
- `manifest.json`：`card_count` 与 `cards` 条目数均为 78；每个条目都有对应图片路径和来源许可字段。
- 原始下载使用 Commons 的 500 px 缩略图，再转为 JPG；原始 PNG URL 和 SHA-1 仅用于来源追溯，交付目录只保留应用所需 JPG 与 manifest。
