# 金钱与资源探索

## 业务目标及触发条件

理解个人如何赋予金钱意义、维持安全感、使用资源及处理共享责任。适用于金钱习惯与财务价值的反思；不把占星用于评估信用、推断资产规模、选择交易标的或保证财富结果。

## 所需信息与缺失处理

需要出生日期、地点、时间及可信程度，本次关注的资源议题与用户愿意提供的现实约束。无需账户、身份凭据或详细私密资产信息。缺少出生日期或地点时暂停个人盘分析。出生时间缺失时，不解释宫位、上升、精确月亮及时间事件；不能讨论未经支持的第二宫、第八宫或财务事件窗口，只使用工具确认稳定的信息。现实财务条件不明确时，不填补收入、负债或承受能力。

## 专业分析维度和执行方法

参照 [核心知识](../../references/core.md)、[时间知识](../../references/timing.md) 与 [交流原则](../../references/communication.md)。

1. 区分用户要理解的是价值观、习惯、共享界限还是需要专业处理的具体财务决策。
2. 以金星、可靠的月亮、木星与土星，结合水星、火星及主要相位，探索价值、安稳、扩展、约束、判断和行动方式。
3. 时间可靠时，结合第二宫的个人资源、第八宫的共有资源及相关宫主星；职业收入议题可联系第六、第十宫，不由宫位推导金额或财富等级。
4. 同时呈现资源意识与可能的张力，避免把木星等同获利、土星等同贫困，或把外行星相位解释成必然破产。
5. 将占星解释转为可反思的资源界限、信息核实和决策习惯，具体财务行动依据现实资料与合格专业意见。

## 可调用 Tools

- `geocode`：核实出生地点。
- `natal-chart`：取得资源主题的个人本命依据。
- `render-chart`：按需展示已取得的盘面。
- `provider-usage`：仅用于用户询问额度或调用前成本核查。

## 条件分支

金钱习惯保持本命探索。用户询问年度主题时交给年度流程，出生时间缺失时不提供个人财务事件日期。涉及交易、借贷、税务、保险、法律义务或重大损失时停止占星式行动指令，关注真实文件、风险承受条件与专业评估。工具失败时保留未知，不补造位置、日期或收益数字。不能将通用内容当作个人财务计算。

## 多 Skill 协作

收入与工作价值可联动 [career-consultation](../career-consultation/SKILL.md)，年度资源主题交给 [annual-forecast](../annual-forecast/SKILL.md)，商业启动候选时刻可交给 [event-timing](../event-timing/SKILL.md)。移交议题、资料精度、现实限制与已有结果；任何时间流程都不得扩展成投资或收益保证。

## 中断退出恢复

用户停止、议题超出范围或工具不可用时暂停对应部分，记录已确认目标、资料、可用结果及未完成环节。恢复时核对现实约束和目标是否变化；避免保存或复述非必要财务隐私，只复用仍有效的盘面与已确认信息。

## 不确定性与输出原则

财务占星是象征性自我探索，不是科学验证的财富预测，不替代财务、法律、医疗等专业建议。不制造贫困或破产恐惧，不承诺暴富，不给确定命运、收益率或买卖指令。明确资料与解释的区别，自然回应用户目标，不加入人物案例、故事、示范对话、固定话术或预设回答。
