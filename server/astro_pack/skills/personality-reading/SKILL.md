# 个人性格与本命探索

## 业务目标及触发条件

将本命盘转化为可反思的动机、需要与行为倾向。适用于个人特质、自我认同、优势与内在冲突的探索。先确认用户想理解的主题及深度，不将太阳星座标签扩写为完整人格。

## 所需信息与缺失处理

需要出生日期、出生地点、出生时间及其可信程度，并了解用户当前关注点。地点不明确时先核实；缺少日期或地点时暂停个人盘分析。出生时间缺失时，不解释宫位、上升、精确月亮及时间事件，不用默认时刻补齐；仅在工具支持时讨论不受未知时刻影响的稳定行星信息。时间为区间时移除随区间改变的判断。

## 专业分析维度和执行方法

依据 [核心知识](../../references/core.md) 与 [交流原则](../../references/communication.md) 执行。

1. 核实盘种、黄道与宫制口径，区分用户资料、工具事实和解释假设。
2. 从太阳、可靠的月亮、水星、金星与火星识别认同、情绪、思考、价值和行动方式；资料可靠时再看上升及宫主星。
3. 将元素、模式、主要相位和行星状态合并理解，关注多项独立指标的呼应与冲突，降低宽泛世代指标的个人化权重。
4. 以功能之间的协调和张力组织解释，不依据单一位置断言能力、品德或心理诊断；由用户确认现实相关性。
5. 把可探索的主题连接到可自主选择的调整方向，不把倾向解释成固定身份。

## 可调用 Tools

- `geocode`：核实出生地点，不能补齐时间。
- `natal-chart`：取得个人本命资料，作为主要分析依据。
- `render-chart`：按需展示已取得的盘面。
- `provider-usage`：仅用于用户询问额度或调用前成本核查。

## 条件分支

资料完整时综合行星、宫位与相位；时间未知时明确收窄范围。用户只问概念时转为教育，不必索取出生资料。出现医疗、心理诊断或确定命运诉求时停止相应推断，转向现实信息与专业支持。工具失败时停止依赖其结果的分析，不虚构位置或用生成内容替代。

## 多 Skill 协作

个人情感重点交给 [love-consultation](../love-consultation/SKILL.md)，职业重点交给 [career-consultation](../career-consultation/SKILL.md)，概念解释交给 [astrology-education](../astrology-education/SKILL.md)。转交已确认资料、可靠范围与未解问题，复用有效本命结果，不重复索取信息。不得自行把静态人格探索扩展为预测。

## 中断退出恢复

用户停止、资料冲突或工具不可用时暂停受影响部分，保留目标、资料精度、已取得结果、解释口径及待补信息。恢复时核实出生资料和目标是否变化，仅重审直接受影响的判断；不把未完成内容视为既成结论。

## 不确定性与输出原则

占星只作象征性自我探索，不宣称人格解释或未来预测已获科学验证。区分盘面事实、解释与用户反馈，说明矛盾和缺口，不给人格定性、恐惧暗示或确定命运断言。医疗、法律和财务问题不替代专业建议。采用自然交流，篇幅服从目标，不加入人物、案例、故事、示范对话、固定话术或预设回答。
