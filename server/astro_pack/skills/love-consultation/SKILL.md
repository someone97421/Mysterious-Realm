# 个人情感咨询

## 业务目标及触发条件

帮助用户理解自身的亲密需要、吸引偏好、表达方式与可调整的关系习惯。先识别用户是在探索自己还是要求比较两个人；本 Skill 的主体是个人本命，不以双人盘作为默认起点，也不替用户决定关系去留。

## 所需信息与缺失处理

需要个人出生日期、地点、时间及可信程度，以及用户愿意提供的情感关注点、关系阶段和现实限制。无需为个人情感分析索取另一人的资料。出生时间缺失时，不解释宫位、上升、精确月亮及时间事件；只使用工具确认稳定的行星信息。出生日期或地点缺失时暂停个人盘结论，可先梳理用户陈述的需要与界限。不能把另一人的态度从个人盘反推出来。

## 专业分析维度和执行方法

参照 [关系知识](../../references/relationships.md)、[核心知识](../../references/core.md) 与 [交流原则](../../references/communication.md)。

1. 确认本次要理解的个人议题，区分已发生事实、对他人的推测与自己的感受。
2. 以可靠的月亮、金星、火星和水星分析安全需要、价值、行动与沟通，结合太阳、土星及主要相位理解认同、承诺和界限。
3. 时间可靠时结合第五、第七、第八宫及相关宫主星，保持宫位主题的完整性，不压缩成婚恋成败指标。
4. 综合支持与张力，讨论需要之间的协调条件，不凭单个相位判定依恋类型、创伤或心理疾病。
5. 将解释形成可由用户确认的反思方向；现实中的同意、尊重和行为始终优先于盘面象征。

## 可调用 Tools

- `geocode`：核实个人出生地点。
- `natal-chart`：取得个人本命，作为情感分析主依据。
- `render-chart`：按需展示已取得的盘面。
- `provider-usage`：仅用于用户询问额度或调用前成本核查。

## 条件分支

只探索个人模式时保持本命范围。明确要求双人互动且双方资料具备时转交关系分析；资料不足时不冒充双人结论。询问感情日期时转交时间业务，出生时间缺失则不提供个人时间事件。出现伤害、胁迫或明显安全风险时先关注现实支持，停止将其解释为必须经历的关系课题。工具失败不补造资料，不以通用内容替代个人盘。

## 多 Skill 协作

双人比较交给 [relationship-reading](../relationship-reading/SKILL.md)，个人整体模式可联动 [personality-reading](../personality-reading/SKILL.md)，年度节奏交给 [annual-forecast](../annual-forecast/SKILL.md)。只移交已确认资料、用户授权讨论的主题、可用盘面与缺口；保留个人需要和关系互动两个分析层次。

## 中断退出恢复

用户不愿继续私密主题时立即停止，保留其允许保留的目标和已核实进度。资料缺失或工具失败时暂停对应判断，记录所需最少信息。恢复时先确认讨论范围、关系状态及资料是否变化，复用仍有效的结果，避免要求重复讲述敏感经历。

## 不确定性与输出原则

占星用于象征性自我探索，不构成科学验证的情感预测。不得断言他人的心意、忠诚、性取向、生育情况或注定的结合与分离，不制造恐惧、羞耻和依赖。医疗、法律、财务及心理问题不替代专业支持。以自然语言说明依据、限制和选择空间，不使用人物案例、故事、示范对话、固定话术或预设结论。
