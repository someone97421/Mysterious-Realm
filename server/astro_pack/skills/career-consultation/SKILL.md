# 职业方向咨询

## 业务目标及触发条件

帮助用户把个人动机、工作需要与现实职业条件放在同一框架内考虑。适用于职业方向、工作方式、公共角色及转变中的价值梳理；不凭盘面指定唯一职业，不保证录用、晋升或收入。

## 所需信息与缺失处理

需要出生日期、地点、时间及可信程度，用户的职业阶段、已具备能力、现实限制与本次决策目标。只收集影响判断的信息，不索取无关单位或身份隐私。缺少出生日期或地点时暂停个人盘分析。出生时间缺失时，不解释宫位、上升、天顶、精确月亮及时间事件；仅讨论工具确认稳定的行星信息，不能以太阳星座代替事业轴。现实职业信息不足时保留建议，不假设学历、资源或能力。

## 专业分析维度和执行方法

依据 [核心知识](../../references/core.md)、涉及时间时的 [时间知识](../../references/timing.md) 及 [交流原则](../../references/communication.md)。

1. 确定用户优先考虑的价值、工作条件、发展目标和可行选择，区分职业现实与占星解释。
2. 从太阳、水星、金星、火星、木星及土星的可靠状态与主要相位讨论认同、学习、合作、行动、扩展和责任。
3. 出生时间可靠时，综合第十宫及天顶、第二宫、第六宫与相关宫主星，分别理解公共角色、个人资源和日常工作，不把它们直接等同职位或收入金额。
4. 综合重复与矛盾指标，讨论偏好的工作组织方式、潜在消耗和需要培养的能力；盘面倾向不能证明现实技能。
5. 将分析连接到可验证的职业探索、信息收集与选择标准；以用户实际机会、专业资质和劳动条件约束建议。

## 可调用 Tools

- `geocode`：核实出生地点。
- `natal-chart`：取得职业探索所需的个人本命。
- `render-chart`：按需展示可靠的相关结构。
- `provider-usage`：仅用于用户询问额度或调用前成本核查。

## 条件分支

方向探索保持本命范围；用户关心年度发展节奏时转交年度流程；关心候选启动时刻时转交择时流程。时间未知时不得提供转职、晋升或其他个人事件日期。涉及劳动争议、资格认定或重大财务承诺时，优先现实资料与相应专业意见。工具失败时暂停相关判断，不补造职业指标或借通用内容充当个人结果。

## 多 Skill 协作

资源与金钱习惯可联动 [finance-reading](../finance-reading/SKILL.md)，年度主题交给 [annual-forecast](../annual-forecast/SKILL.md)，候选时刻交给 [event-timing](../event-timing/SKILL.md)。移交职业目标、现实限制、出生资料精度、已有盘面及缺口；避免把方向、时间和收益结论混成同一种保证。

## 中断退出恢复

用户停止或职业目标改变时暂停，保留已确认的选择条件、资料、可用结果及尚待核实的信息。恢复时更新职业状态与现实机会，核对出生资料是否修正，只重审受变化影响的部分。工具失败恢复后，从未完成环节继续，不重复已完成的有效步骤。

## 不确定性与输出原则

职业占星属于象征性自我探索，不是科学验证的能力测评或职业预测。不制造失败恐惧，不断言命定职业，不承诺成功、晋升与收益。医疗、法律和财务问题不替代专业建议。区分资料、解释和待核实假设，以自然交流提供可选择的探索方向，不加入人物案例、故事、示范对话、固定话术或预设回答。
