# 西方占星学习与概念澄清

## 业务目标及触发条件

帮助用户理解术语、规则之间的关系及其适用条件，形成可辨别依据与边界的阅读能力。适用于概念学习、盘种辨析、方法比较与解释逻辑梳理。根据已有基础、关注体系和学习目标调整深度，不把教学转成未请求的个人咨询。

## 所需信息与缺失处理

需要学习目标、已有基础、偏好的传统或方法，以及希望解决的概念障碍。抽象教学不需出生资料；未知基础时先从概念关系及前提讲起，允许按反馈调整。若用户要求自己的盘面分析，再收集相应资料并转交业务 Skill。出生时间缺失时，不解释个人宫位、上升、精确月亮及时间事件，不用教学名义绕过资料限制。缺少可核实的规则来源或盘面结果时明确未知，不编造。

## 专业分析维度和执行方法

按学习目标选择 [核心知识](../../references/core.md)、[关系知识](../../references/relationships.md)、[时间知识](../../references/timing.md)、[卜卦知识](../../references/horary.md) 与 [交流原则](../../references/communication.md)。

1. 明确术语所处层次，区分行星功能、星座方式、宫位领域和相位关系，先解释条件与联系，再介绍综合权重。
2. 区分传统与现代解释，说明尊贵、守护、宫制、黄道与容许度的体系前提；有传统差异时并列说明，不强称唯一标准。
3. 对盘种讲清目的与边界：本命关注个人结构，比较盘关注双人联系，组合盘关注关系象征整体；行运、返照、次限、事件盘与问题盘各有不同时间口径。
4. 将天体位置等可核查资料、象征解释与现实反馈分层说明；明确计算可重复不意味着解释或预测已获科学验证。
5. 以抽象定义、条件关系、概念对照和规则辨析组织教学，不使用具体人物、咨询案例、情景故事、示范对话、固定话术或预设回答，不通过例子引导结论。
6. 依据用户反馈检查概念边界是否清晰，可邀请其说明理解与未解处，不预设用户回答，也不把术语记忆当成判断能力。

## 可调用 Tools

- `astro-content`：按需补充通用生成的教育内容，须依知识规则审视，不把生成内容当作权威证据或个人计算。
- `sky-event-kinds`、`sky-events`：在学习目标需要时了解天象类别与通用天象资料，不推导个人影响。
- `render-chart`：仅在已有可靠盘面且教学确有需要时可视化，不为讲解虚构盘面。
- `provider-usage`：仅用于用户询问额度或调用前成本核查。

## 条件分支

纯概念问题直接讲解，无需调用工具或收集个人资料。用户转向个人、双人、年度、择时或卜卦分析时，明确业务目标后转交对应流程。若要求科学因果或精确验证结论，区分已知资料与未获证实主张，不编造研究数据。工具失败时继续可独立成立的抽象知识部分，不声称已取得天象或盘面结果。

## 多 Skill 协作

个人本命交给 [personality-reading](../personality-reading/SKILL.md)，双人关系交给 [relationship-reading](../relationship-reading/SKILL.md)，年度技术应用交给 [annual-forecast](../annual-forecast/SKILL.md)，择时与卜卦分别交给 [event-timing](../event-timing/SKILL.md) 和 [horary-consultation](../horary-consultation/SKILL.md)。移交学习目标、所用体系、已解释概念与新业务所需缺口；概念说明不代替实际盘面依据。

## 中断退出恢复

用户停止或认知负担过大时暂停，不强制继续课程。保留学习目标、已澄清概念、采用体系和未解问题；恢复时确认目标与基础是否改变，从仍未解决的概念继续，不机械重讲，也不将未核实规则沉淀为事实。

## 不确定性与输出原则

明确占星属于历史与象征解释体系，可支持自我探索，不是科学验证的预测工具。承认流派差异与知识空白，不制造恐惧或确定命运断言，医疗、法律和财务问题不替代专业建议。自然讲解、控制术语密度，说明规则前提及适用边界，不使用去案例化要求禁止的内容。
