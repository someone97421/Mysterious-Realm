# 年度主题与发展节奏

## 业务目标及触发条件

将个人本命、行运、太阳返照与次限分别置于合适层次，整理目标周期的重点及可准备的方向。适用于年度规划、返照周期理解与阶段性回顾；先确认用户采用公历年、返照周期还是其他明确观察期，不把周期混用。

## 所需信息与缺失处理

需要出生日期、地点、准确时间及可信程度、目标观察期、关注领域；返照分析另需目标返照周期与返照地点口径。地点采用出生地还是实际所在地应事先确认。出生时间缺失时，不解释宫位、上升、精确月亮及时间事件，暂停个人年度判断，转为明确标注的通用天象整理或等待资料。出生时间为区间时，只保留工具支持且跨区间稳定的部分，不生成精细日期。不得用返照盘补齐缺失本命资料。

## 专业分析维度和执行方法

依照 [时间知识](../../references/timing.md)、[核心知识](../../references/core.md) 与 [交流原则](../../references/communication.md)。

1. 明确观察期与现实目标，以本命中相关行星和可靠宫位作为解释背景。
2. 读取个人行运日历，整理长期背景、主要接触过程和逆行重复，不将同一过程拆成多个必然事件；日期只引用实际返回资料。
3. 在本命背景下理解太阳返照的主要主题，说明返照周期通常跨公历年，地点选择会影响宫位与轴点。
4. 以次限观察象征性发展，明确其不是未来实测天象；优先相关且资料可靠的变化，不补造推进月亮、轴点或相位。
5. 分别呈现各技术支持、冲突与缺口，再综合可关注的阶段；主题呼应不等于科学证实或事件保证。
6. 将周期主题连接到现实准备与复盘，不凭单次精确相位承诺外部结果，不推断死亡、疾病、怀孕或收益。

## 可调用 Tools

- `geocode`：核实出生地与返照地点。
- `natal-chart`：建立或复用可靠的本命背景。
- `transit-calendar`：取得目标周期的个人行运过程。
- `transits`：按需查看特定阶段的个人行运。
- `solar-return`：取得已明确周期及地点口径的太阳返照资料。
- `secondary-progressions`：补充次限象征发展资料。
- `sky-event-kinds`、`sky-events`：仅用于明确标注的通用天象整理。
- `render-chart`：按需可视化已有的相应盘面。
- `provider-usage`：仅用于用户询问额度或调用前成本核查。

## 条件分支

资料充分时按目标选择所需技术，不为完整感无差别调用。返照地点未定时暂停地点敏感的结论；单项工具失败时只交付其他已取得的部分，明确不是完整多技术综合。出生资料不足时不能将通用天象或生成内容包装成个人年运。具体择时、单日指引或卜卦诉求分别转交对应业务，不用年度判断代替。

## 多 Skill 协作

职业与资源背景可分别联动 [career-consultation](../career-consultation/SKILL.md) 和 [finance-reading](../finance-reading/SKILL.md)，短期观察交给 [daily-guidance](../daily-guidance/SKILL.md)，候选时刻比较交给 [event-timing](../event-timing/SKILL.md)。移交周期、资料精度、现实目标、技术来源与未完成项，不能把不同技术的重复结论累计成预测概率。

## 中断退出恢复

用户停止、资料冲突或工具失败时暂停相应层次，保留观察期、返照地点口径、已有结果及待补资料。恢复时核对周期是否改变、地点与出生资料是否修正，重审直接依赖的结果；不将上一周期的主题沿用到新周期。

## 不确定性与输出原则

年度占星是象征性探索，不是科学验证的未来预测。输出相关主题、实际支持的时间范围、分歧与现实选择，精度不得超过资料，不制造恐惧或确定命运，不承诺事件与收益。医疗、法律和财务问题不替代专业建议。保持自然交流，不加入人物案例、故事、示范对话、固定话术或预设回答。
