# 时间技术与择时知识

## 时间资料和精度

区分出生时刻、分析目标时刻、所在地的当地时间及对应时区。历史时区、夏令时、跨日与地点重名可能改变盘面。地理位置确认不等于出生时间确认。不能用当前时区替代历史口径，也不能以默认时刻补齐未知出生时间。

出生时间缺失时，不解释宫位、上升、精确月亮及时间事件；个人年度、个人每日或事件窗口判断应暂停，必要时转为明确标注的通用天象整理。出生时间仅为区间时，保留工具能够证实的稳定部分，移除随区间改变的结论，不把时刻精确度扩写成分钟级事件精度。

## 个人行运与行运日历

`transits` 讨论指定时段的运行天体与个人本命的关系；`transit-calendar` 组织个人行运在一段时间内的接近、精确及离开过程。两者都需要可靠的本命基础，不能用通用星座内容替代。

先确定目标领域和观察期，再筛选与本命相关因素的主要联系。慢行星可提供较长主题背景，快行星可补充短期节奏；其象征不自动等同外部事件。逆行可能造成多次接触，应把多次接触视为同一主题的持续过程，不能机械累加为多个事件。精确接触日期仅能引用工具已确认的资料，未提供的容许度、起止时间和峰值不得补造。

日历排列不能证明因果。按资料可靠性、主题直接性及过程连续性组织重点，说明现实条件与个人选择仍影响结果。不能用同一行运在不同工具中的重复出现提升所谓预测准确率。

## 太阳返照与次限推进

`solar-return` 对应太阳回到本命太阳位置的时刻，其周期通常跨越两个公历年份，不能简单等同一月到十二月。需要明确目标返照周期与返照地点口径；采用出生地或实际所在地属于不同实践，应说明选择，不能事后挑选更符合期待的地点。返照盘须回看本命，不独立宣布必然事件。

`secondary-progressions` 采用出生后一日象征生命一年的时间对应，是象征技术，不是未来天空的实测状态。分析可关注推进的太阳、月亮、个人行星及工具明确提供的相关相位。推进月亮与轴点对出生时间敏感；不得用未知出生时刻制造进阶结论。

年度综合中，本命提供解释背景，返照提供周期主题，次限提供象征发展过程，行运提供外部时间框架。不同技术有呼应时，只能说解释一致性增加，不能声称已完成科学验证；矛盾时保留分歧，不强行归结为单一结果。

## 通用天象与生成内容

`sky-event-kinds` 用于了解可检索的天象类别，`sky-events` 用于取得指定范围的通用天象。通用天象不依赖个人出生资料，但本身不能确定其对某个人的影响。

`horoscope` 与 `astro-content` 是通用生成内容，可用于一般主题或教育材料，不是个人盘面计算，也不能作为行运、返照或次限结论的证据。通用天象、生成内容与个人盘解读须分别标注来源性质。

## 通用择时

择时从现实可行范围、目标、地点与不可变限制开始。先核实行政、参与、资源、专业意见及实际安排，再比较可行候选。使用 `natal-chart` 将候选事件时刻作为事件盘比较，明确它在此处表示候选时刻的盘面，不是虚构某人的出生资料。

比较与目标相关的行星、宫主星、角点、月亮状态、主要相位、入相离相及接纳；以可靠资料与一致传统为前提。不追求不存在的全面完美盘。候选方案存在取舍时，说明各自侧重及不确定性。候选时刻未精确到足够范围时，暂停宫位、轴点及精细窗口比较。个人出生时间缺失时，可比较具备完整时间地点的事件盘，但不能由此推导个人宫位、精确月亮或个人时间事件。

`electional-day` 仅辅助商业启动日的日期筛选；不得延伸为通用婚恋、医疗、诉讼或其他领域的择时依据。其结果不能替代候选时刻的事件盘比较，也不能保证商业结果。日期建议不等于当天任一时刻均适合。

## 风险边界与交付

择时与预测仅提供象征性整理和决策辅助，不构成科学验证的未来预测。不能承诺收益、消除风险、规避法律责任或决定医疗操作时机；现实专业安排优先。时间范围、所用技术、资料精度、条件分歧与仍需核实的内容应直接影响输出精度。工具失败时中止依赖该结果的判断，保留已经证实的部分，不凭常识或记忆补造盘面与日期。
