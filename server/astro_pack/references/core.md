# 西方占星核心知识

## 认识边界与证据层级

占星是一种历史形成的象征解释体系，可用于整理经验、价值与选择。盘面计算的可重复性不等于其人格归因、关系判断或未来预测已获科学验证。天体位置、所用历法、时区与坐标属于可核查资料；占星含义属于解释框架；现实经历属于需由当事人确认的信息。三者不得混写为同一种证据。

解释以已取得的盘面资料为限。出生时间缺失时，不解释宫位、上升、天顶、精确月亮位置及时间事件；不能把默认时刻当作真实出生时刻。仅在工具明确给出且不受未知时刻影响时，讨论稳定的行星星座或相位。日期、地点或时区有疑义时，先说明受影响的结论并缩小范围。不能凭性格描述反推出生时间并当成定论。

## 行星：功能与动机

- 太阳：自我认同、意志、生命方向与表达主体性的方式。
- 月亮：情绪调节、安全需要、习惯与照顾方式；位置和相位对时间较敏感。
- 水星：思考、信息组织、学习与沟通。
- 金星：价值取向、愉悦、审美、亲近与关系中的协调。
- 火星：行动、欲望、竞争、冲突处理与界限表达。
- 木星：扩展、意义、信念、学习与资源放大；扩展也可能成为过度。
- 土星：结构、责任、限制、耐心与长期建设；限制不等同惩罚。
- 天王星：独立、改变与既有模式的突破。
- 海王星：想象、理想、共情与边界模糊。
- 冥王星：权力、深层改变、控制与失控议题。

外行星在单一星座停留较久，其世代含义通常比个人特征更广。个人化解读需看其与个人行星、轴点或宫位的可靠联系，不能仅凭外行星星座塑造完整人格。

## 星座：表达方式

星座修饰行星功能的表现方式，不代替行星本身，也不能把太阳星座等同整个人。

四元素描述倾向：火重行动与愿景，土重落实与资源，风重概念与交流，水重感受与联结。三模式描述组织方式：基本重启动，固定重维持，变动重调整。元素或模式的多寡只能形成待核实的倾向，不能证明能力、品德或心理状态。

十二星座可用抽象表达主题区分：白羊侧重直接启动与自主，金牛侧重稳定与感官价值，双子侧重信息交换与多向探索，巨蟹侧重照顾与归属，狮子侧重创造与主体表达，处女侧重辨析与改善，天秤侧重协商与关系平衡，天蝎侧重深度联结与控制边界，射手侧重意义与视野扩展，摩羯侧重结构与长期责任，水瓶侧重群体理念与独立思考，双鱼侧重想象、共情与边界流动。这些是行星表达的象征修饰，不是十二类人的固定性格，也不提供事件结论。

黄道体系须前后一致；热带与恒星体系不能无说明地混用。星座、实际天文星座与宫位不是同一概念。不存在把某一星座天然等同某一宫位的通用替代规则。

## 宫位：生活领域

宫位依赖准确时刻、地点与宫制。第一宫关乎自我呈现和行动起点；第二宫关乎个人资源与价值；第三宫关乎日常学习、交流与近邻；第四宫关乎根基、家庭与私生活；第五宫关乎创造、玩乐与浪漫表达；第六宫关乎日常劳动、习惯与照料；第七宫关乎伴侣及明确的一对一关系；第八宫关乎共有资源、依赖与深层转变；第九宫关乎高等学习、世界观与远行；第十宫关乎公共角色、事业与声望；第十一宫关乎群体、友谊与长期愿景；第十二宫关乎隐退、隔离、隐性过程与内在生活。

宫主星把一个领域的主题连接到其所落领域及状态。角宫通常增加显著性，但不能直接换算成成败。空宫不表示该生活领域不存在。宫制改变造成边界差异时，应披露差异并保留稳定主题，不能挑选最符合预想的宫制。

## 相位：功能之间的关系

合相描述功能聚合，其性质取决于相关行星；六分相常被解释为可利用的合作条件；四分相强调摩擦、驱动力与调整；三分相强调流畅，也可能形成惯性；对分相强调两极、关系镜映与整合。相位并不自动决定事件的好坏。

相位有效性须有工具提供的位置或相位资料支持，并说明所用容许度口径。更紧密的主要相位通常优先于宽泛或次要联系，但仍须看相关行星、可靠宫位及主题关联。不能为了凑出图形而扩大容许度，不能把相位数量直接换成幸福、能力或风险分数。

入相与离相描述相位是否趋近精确；在卜卦中尤其重要。须依据真实运动、速度与逆行状态判断，不能仅按黄经大小推断。缺少运动资料时不补造。

## 尊贵、失势与状态

传统本质尊贵包括入庙、擢升、三分、界与面；后几项须采用明确且一致的传统表。传统七曜的入庙关系为：太阳狮子、月亮巨蟹、水星双子与处女、金星金牛与天秤、火星白羊与天蝎、木星射手与双鱼、土星摩羯与水瓶。传统擢升关系为：太阳白羊、月亮金牛、水星处女、金星双鱼、火星摩羯、木星巨蟹、土星天秤。失势与落陷分别为入庙与擢升星座的对宫。

这些术语表达特定传统中的资源与运作条件，不是人的等级、道德、健康或价值判决。无本质尊贵不等于失败。偶然状态另看可靠宫位、顺逆行、速度、与太阳的关系、受助受克等，不能将其混同本质尊贵。昼夜区分及接纳须按所选传统明确处理；外行星的传统尊贵归属没有统一共识，不能伪装为古典定则。

## 综合权重与解释顺序

1. 先核实资料完整性、盘种与解释体系，再界定本次问题。
2. 按问题选择相关行星、可靠宫位与宫主星，先处理直接指标。
3. 结合行星功能、星座表达、相位互动与状态，避免单指标决定结论。
4. 关注独立指标之间的呼应；同一指标的不同说法不能充当多份证据。
5. 对冲突指标同时保留，说明其可能在不同环境、需求或阶段下表现。
6. 用当事人确认的经历校验相关性，保持未确认部分为假设，不为维持解释而改写事实。

权重是论证顺序，不是经过科学验证的量化模型。输出应给出支持依据、可替代解释和现实行动空间，不给确定命运、诊断、人格定性或必然事件结论。
